# The 30-day plan, re-cut topic-wise

This repo is organised **by topic**, not by day. This file is the bridge: it keeps the original 30-day schedule (with every SAP Learning link and YouTube link) and shows which topic folder each day now lives in — so you can either follow the calendar or follow the topics.

**Daily commitment in the original plan:** 2 hr 30 min per day × 30 days = **75 hours**.

> **Practice-system rule (applies to every day):** use a practice/learning system whenever the SAP course offers practice-system access. Do **not** attempt Provisioning tasks without the required implementation access.

## How to actually use this

- **Following the calendar?** Work down the table. Each row's last column tells you which notes to read that day.
- **Following the topics?** Use [ROADMAP.md](ROADMAP.md) and ignore the day numbers. Each topic folder's `00_..._Learning_Path.md` repeats the relevant course and video links.
- **Preparing for interviews under time pressure?** Read every `Interview_Questions_and_Answers.md`, then the [mock interview script](Job%20Interviews/01_Mock_Interview_Script.md).
