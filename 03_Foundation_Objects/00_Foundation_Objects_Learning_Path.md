# 03 Foundation Objects — Learning Path

Foundation Objects are the **shared structures** every employee record points at. Employee data says *"this person is in Department D-450"*; the Foundation Object says what D-450 *is*, which business unit it belongs to, and which cost centre it defaults.

Get this folder right and Job Information almost configures itself. Get it wrong and you will be unpicking it for the rest of the project.
